# index module

Public re-export barrel for the library. These module docs describe the upstream
TypeScript source of [stackedlol/ascii-sharks](https://github.com/stackedlol/ascii-sharks)
(as integrated by [yxflc11/dsh-asciishark](https://github.com/yxflc11/dsh-asciishark));
see [go-port.md](go-port.md) for the Go package mapping.

## API

```
export OceanEngine from "./engine"
export AsciiRenderer, paintGrid from "./renderer"
export World, SharkKind, SharkSpec from "./world"
```
